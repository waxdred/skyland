== Synopsis

// tag::synopsis[]
aerospace master [-h|--help] (on|off|toggle|swap|focus)

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}: one master window (master-ratio percent wide) and the other windows
stacked on the side; new windows go to the bottom of the stack. on / off / toggle
switch the focused workspace (remembered), swap swaps the focused window with the
master, focus focuses the master.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]
